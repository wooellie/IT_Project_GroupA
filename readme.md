# 🌟 Project Guide: Internet Technology (M) – Design Specification

This assignment is **Coursework 4**, a group project worth ==**15%**== of your total grade. Our goal is to design (but not yet fully implement) a web application.

### 📅 ==**Section 1: Key Information**==
*   **Deadline:** ==**12 February 2026**== at ==**4:30pm**==.
*   **Submission Format:** One **PDF file** (exported from PowerPoint) submitted via Moodle by one team member.
*   **App Requirements:** The proposed web app must include:
    1.  **User Authentication** (Login/Signup).
    2.  **Database Interaction** (Storing and retrieving data).
    3.  **Visual Appeal** (Intuitive UI).
    4.  **User Input** (Data that is saved and used by the app).

---

### 📝 ==**Section 2: Deliverables (Task Breakdown)**==
You can divide the PowerPoint slides among the team as follows:

#### **Module A: Overview & Requirements (1 Member)**
*   **Application Overview (1 slide):** Define the intended users, the problem it solves, and its value.
*   **MoSCoW Specification (1 slide):** ==**6-10**== User Stories in the format: *"As a..., I want..., so that..."*. Label them as **Must, Should, Could, or Won't**.
    *   *Note:* "Must" requirements **must** include login, database interaction, and user input.

#### **Module B: Architecture & Database Design (1-2 Members)** 
*   **System Architecture Diagram (1 slide):** High-level components and external APIs.
*   **ER Diagram (Max 2 slides):** ==**Crucial: Worth 8 Marks**==. Must use **Compressed Chen notation** and describe attributes for each entity.

#### **Module C: Site Map & UI Design (1-2 Members)**
*   **Site Map (1 slide):** Show site organization and link pages to "Must" requirements.
*   **Wireframes (2-5 slides):** UI sketches for core functionality.
    *   *Note:* Must illustrate all "Must" requirements.

#### **Module D: Accessibility & Admin (1 Member)**
*   **Accessibility Plan (1 slide):** List ==**5**== **WCAG 2.2** guidelines we will follow (e.g., contrast, keyboard focus).
*   **Appendix (1 slide):** Specify each member's contribution (==**%**==) and the **AI Use Statement**.
